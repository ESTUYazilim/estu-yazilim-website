---

## Teknolojiler

- **React + Vite**
- **Material UI (MUI)**
- **React Router DOM**

---

## Kurulum ve Çalıştırma

```bash
# 1. Projeyi klonla
git clone [https://github.com/estuyazilim/estu-yazilim-website.git](https://github.com/estuyazilim/estu-yazilim-website.git)
cd estu-yazilim-website

# 2. Bağımlılıkları yükle
npm install

# 3. Geliştirme sunucusunu başlat
npm run dev
```

---

## Klasör Yapısı

```text
├── public/                 # Logolar, yazı tipleri ve ekip fotoğrafları (public/ekip/)
├── src/
│   ├── components/         # Ortak arayüz bileşenleri (Navbar, Footer, Layout vb.)
│   ├── pages/              # Sayfalar (HomePage, Ekibimiz, Hakkımızda vb.)
│   ├── ThemeContext.jsx    # Dark/Light tema ayarları
│   └── main.jsx            # Sayfa rotaları (Router) ve giriş noktası
```
